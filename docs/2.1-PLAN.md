# RiftLens 2.1

Date: 2026-08-18  
Workspace: this repository  
Public release on GitHub: 2.1.0 (2026-08-18). Previous public zip: 2.0.0 (2026-07-26).

This note freezes the product conclusions from the 2.0 review, then records what 2.1 actually changes. It is the implementation brief, not a marketing page.

## Product read

RiftLens is a privacy-first, screen-only Korean-server chat translator for Windows. It never reads game memory. The player boxes a rectangle, the app copies pixels, OCRs them locally, classifies the line, and only then may send free player chat to a BYOK OpenAI-compatible endpoint (DeepSeek by default). HUD, pings, and fixed system text stay local.

That architecture is the right product. The 2.0 pain is not “needs more AI.” It is setup friction, dishonest UI status, a poster-sized WebView that does not behave like a launcher, silent speech with no reason, and capture coordinates that die when the game window moves.

## What 2.0 already does well

- Screenshots never leave the machine. Only classified text can cross the network.
- Player chat is always translated. Optional system categories default off.
- Deterministic Korean / Chinese / English Ping and HUD routing runs before free-form AI.
- A final speech gate re-reads the latest switches so a queued line cannot bypass a toggle the player just turned off.
- Semantic validation may silence speech while keeping literal overlay lines.
- API keys live in Windows Credential Manager.

## Confirmed problems

| Surface | Evidence | Decision |
| --- | --- | --- |
| Main window | Fixed 1536×1004 stage, orb art, 1-2-3 poster numbers, fake chat skeleton | Rebuild as a responsive launcher. Status must be true. |
| Region | Absolute pixels; named presets with empty rectangles | Store window-relative fractions; ship real default ratios. |
| Overlay control | 48 px wave; pause/mute/reselect buried in a right-click menu | Expose pause, mute, and reselect while hovered. |
| Overlay copy | Speech can be silenced with no badge | Show a one-line reason on the overlay and in history. |
| Partial lines | A mid-scroll fragment can flush after `SummaryWindowMs` | Wait one extra window when the last line looks incomplete. |
| AI node | Large JSON (intent, speechAct, evidence, spokenSummary) for every free-chat turn | Ask the model only for `displayLines` + toxicity. Speak locally. |
| Update button | `CheckUpdate` only toasts “local development build” | Keep the control, tell the truth, do not pretend a channel exists. |
| Voice page | Dense A/B/C strategy board on first open | Three presets, with the old switches under Advanced. |
| Diagnostics | Evaluation capture sits on History | Move maintainer tools to Settings. |

## Pipeline decisions (kept)

1. Capture stays GDI `CopyFromScreen` in 2.1. `Windows.Graphics.Capture` is the next capture upgrade, not this release.
2. OCR stays bundled PP-OCRv5 + Tesseract fallback. Do not put a model on every frame.
3. Classification stays local. Do not send Unknown or HUD text to the model “just in case.”
4. AI stays on free player chat only. DeepSeek remains the default because it is the documented OpenAI-compatible BYOK path; the interface does not change.
5. Overlay and speech stay separate. Literal lines can show when speech is refused.

## 2.1 scope

Shipped in this source tree as **2.1.0**:

1. Launcher WebUI remains the 2.0 visual. No second redesign in this release.
2. Honest OCR / API / region / speech status on the existing home page.
3. Host still stores a last-capture preview for later UI work; 2.1 does not replace the 2.0 home layout.
4. Per-category voice switches stay on the existing Speech page.
5. Evaluation and diagnostic export live under Settings.
6. Overlay control: pause, mute, reselect.
7. Overlay and history show why a line was not spoken.
8. Capture regions can follow the League client window; presets have real ratios.
9. Incomplete last lines wait one extra aggregation window.
10. Translation prompt asks for one-to-one `displayLines` (and a toxicity flag). Spoken text is assembled locally and still passes `TranslationSemanticGuard` + `FinalSpeechPolicy`.

Out of 2.1:

- Graphics Capture / DXGI duplication
- Dual-UI deletion (native GDI workspace stays as unused fallback code)
- A real update channel
- Changing the privacy boundary
